# Process

## Initial Ideas

I began with three ideas:

1. AI may make writing code less necessary, but reading and evaluating code will remain important.
2. Designers do not need to become professional programmers, but they should understand computational systems.
3. AI makes solutions easier to obtain, but receiving a solution is not necessarily the same as understanding it.

I used ChatGPT to help organize these ideas into an essay structure. I did not begin by asking it to generate a complete essay. My goal was to first define my own position and then use AI to test and organize the argument.
