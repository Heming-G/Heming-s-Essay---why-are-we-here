# Why Learn Programming When AI Can Write Code?

## Working Argument

AI may reduce the need for designers to write code from scratch, but this does not make understanding programming irrelevant. For designers, the purpose of learning programming is shifting away from competing with machines at writing syntax. Instead, designers need enough computational knowledge to read, evaluate, modify, and direct the systems that increasingly produce code for them.

## Ideas to Develop

### Reading may become more important than writing

AI can already generate working code quickly, but working code is not necessarily good code. Someone still needs to identify mistakes, understand what can be optimized, and judge whether the result actually matches the intended design.

### Understanding the medium

Designers do not necessarily need to become professional programmers. However, if computation is part of the medium they work with, they should understand how that medium behaves. This becomes especially important in technical art, interactive design, and generative systems.

### A solution is not the same as understanding

AI makes answers much easier to obtain. For beginners, this can create a temptation to copy a working solution without understanding why it works. The result may solve the immediate problem while leaving the learner unable to solve the next one independently.
